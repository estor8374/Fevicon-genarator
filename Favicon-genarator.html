Frequently Asked Questions

What is an ICO file? ▼
An ICO file is an image file format for computer icons in Microsoft Windows. It is widely used on the web as a "Favicon" (favorites icon), which is the small image displayed in the browser tab next to the page title.
What is the best size for a Favicon? ▼
The standard size for a browser favicon is 16x16 pixels. However, it is recommended to include 32x32 pixels for taskbar shortcuts and 48x48 pixels for desktop icons to ensure they look good on high-resolution screens.
How do I add a favicon to my website? ▼
After downloading your ICO file, upload it to your website's root folder. Then, add the following code to your HTML <head> section:
<link rel="icon" href="/favicon.ico" type="image/x-icon">
